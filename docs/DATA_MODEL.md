PostgreSQL 15+ · Drizzle ORM 0.45 · schema in `src/db/schema/*.ts` · barrel `src/db/schema/index.ts`.

## 2. Column conventions

- `casing: "snake_case"` is configured → write camelCase keys, never pass column names: `firstName: text()`.
- Helpers from `_shared.ts`: `pk()`, `tstz()`, `...timestamps`, `...createdAtOnly`, `moneyMinor()`, `currencyCode()`, `countryCode()`, `emptyJsonObject`, `emptyTextArray`.
- Status/type columns: `text({ enum: CONST_ARRAY })`. Export the const array + its type from the domain file (e.g. `export const JOB_STATUSES = [...] as const`).
- Every FK column gets an index. Name indexes explicitly: `<table>_<cols>_idx` / `_uq`.
- Choose `onDelete` deliberately: `cascade` for owned children, `set null` for optional actors/links, default (restrict) for business records that must not silently disappear.
- Human-readable codes (`code text not null` + unique index) on: jobs (JOB), applications (APP), requirement_requests (REQ), support_tickets (TKT), invoices (INV yearly), enquiries (ENQ), leads (LEAD), offers (OFR), placements (PLC), interviews (INT), partner_submissions (SUB), payments (PAY), refunds (RFD), certificates (CRT), skill_assessments (ASM), courses (CRS), batches (BAT), campus_drives (DRV), mobilisation_records (MOB). Generated by `nextCode(prefix)`.
- Money: `amountMinor: moneyMinor()` + `currency: currencyCode()` — never assume INR.
- Sensitive identifiers (passport no., national ID, bank account): store encrypted with `encryptField()` in a `*Encrypted` text column + a non-sensitive `*Last4` column for display.
- Files: reference `files.id` with a real FK (files is layer 2) — `resumeFileId: uuid().references(() => files.id)`.
- Do **not** declare Drizzle `relations()`; use explicit joins.
- Full-text search: add a generated `tsvector` column with a GIN index where search matters (jobs, candidate search, CMS entries). Use `customType` for tsvector. `pg_trgm` is installed for fuzzy matching.
- Soft delete (`deletedAt`) for business records users can delete (jobs, documents, portfolio items, CMS entries); hard delete only for ephemeral data.
- Append-only histories (stage history, approval events, consent) never update rows.
